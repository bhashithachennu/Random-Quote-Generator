# Random Quote Generator

A responsive Random Quote Generator built using HTML, CSS, and JavaScript.

The application displays inspirational quotes dynamically with changing backgrounds, animations, and interactive features.

## Features

- Generate random inspirational quotes
- Display quote author details
- Dynamic background gradient changes
- Smooth fade animation effects
- Copy quotes to clipboard
- Share quotes through WhatsApp
- Real-time date and time display
- Generate quotes using Space key
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Clipboard API
- WhatsApp Sharing API

## Project Description

This project is a frontend web application that generates random motivational quotes.

JavaScript is used to dynamically update quotes, authors, backgrounds, animations, and user interactions without refreshing the page.

The application provides a simple and interactive user experience.

## How to Run

1. Clone this repository.

2. Open `index.html` in any web browser.

3. Click the "New Quote" button to generate quotes.
